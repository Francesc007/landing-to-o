# Lecciones del proyecto

## Caché de un service worker viejo en localhost:3000

- Qué pasó: la página se caía con `Cannot read properties of undefined (reading 'map')` en Historia, y el aviso de Next decía “stale”. Las fotos de proyectos no llegaban a verse.
- Por qué: en el puerto 3000 seguía registrado un service worker de otro sitio (`sw.js`, caché `myan-static-v6`). Servía JavaScript viejo aunque este proyecto ya no tiene service worker. El archivo en disco estaba bien; el navegador no lo pedía (`transferSize` 0).
- Cómo se resolvió: anular ese registro y borrar su caché, y volver a cargar la página. Este proyecto no registra `serviceWorker`.
- Cómo evitarlo: si la página falla solo en el navegador y los scripts salen de caché, revisar `navigator.serviceWorker.getRegistrations()` antes de cambiar el código. No hace falta tocar los archivos del proyecto.
